# sonik-l10n

Translation JSON files for Sonik's web UI (`sonik-webui`) — copied from `RoPieee/ropieee-l10n`. `en-US.json` is the master file: both the default language and the fallback when a specific translation is missing a key. Keys/subkeys are used by the software and must not be renamed.

**Always read `/home/harry/dev/SONIK/sonik-ai/CLAUDE.md` first** (shared Sonik/RoPieee ecosystem context) and follow its instructions — it covers naming, branding, migration status, and which repos are live across the ecosystem.

This repo is **public** (like its upstream `ropieee-l10n`) — community translators submit PRs directly against it.
